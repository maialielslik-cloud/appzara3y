# 🌾 Zera3ee — Smart Agriculture Application

**Zera3ee (زراعي)** is a Flutter mobile application designed to bridge the gap between modern technology and the agricultural sector.

The application provides farmers and agriculture enthusiasts with smart tools for agricultural assistance, plant disease diagnosis, crop information, weather updates, and an agricultural e-commerce experience — all through a clean and minimalist UI/UX.

---

## 🚀 Project Overview

Zaraee was developed as a user-centric mobile solution that combines **Flutter, Firebase, and AI-powered features** to provide practical agricultural services in one application.

The project focuses on delivering a simple and seamless experience while using modern technologies to solve real agricultural needs.

---

## ✨ Key Features

### 🤖 AI-Powered Smart Assistant

* Integrated **Google Gemini API**.
* Provides instant agricultural advice through a smart chatbot.
* Helps users get answers and guidance related to agriculture.

### 🔍 Plant Disease Diagnosis

* Allows users to capture or upload a plant image.
* Analyzes the image to help identify possible plant diseases.
* Provides an instant diagnosis experience through AI-powered functionality.

### 🛒 Agri-Store

* Agricultural e-commerce section for purchasing:

  * Seeds
  * Agricultural equipment
* Includes integrated payment options:

  * Vodafone Cash
  * Credit Cards

### 📖 Crop Guide

Provides useful information about different crops, including:

* 🌱 Planting schedules
* 💧 Irrigation
* 🌿 Fertilization
* 🌾 Crop care

### 🌤️ Weather

* Provides weather-related information to help users make better agricultural decisions.

### 🔐 Authentication

* User registration and login using **Firebase Authentication**.
* Secure user authentication and account management.

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/maialielslik-cloud/appzara3y.git
```

### 2. Navigate to the project

```bash
cd appzara3y
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run
```

> **Note:** Firebase configuration and Gemini API credentials may be required to run all application features locally.
